# shotgun

교사 연수 오프닝용 '가상 책상 샷건' — `index.html` 하나만 브라우저로 열면 됩니다.

- 클릭 / 스페이스바(또는 Enter): 쾅! (5단계에서 책상 반토막)
- 더블 클릭(또는 R, Esc): 처음 상태로 리셋
- F: 전체 화면 전환
- 이미지: `index.html`과 같은 폴더에 `fist.png`, `desk.png`(배경 투명 PNG)를 두면 자동으로 사용합니다. 없으면 코드로 그린 책상/주먹이 나옵니다.
- G: 책상 윗면(금이 그려지는 영역) 가이드 표시 — `CONFIG.DESK_TOP_QUAD`로 맞추세요. 주먹 크기는 `CONFIG.FIST_SCALE`.
